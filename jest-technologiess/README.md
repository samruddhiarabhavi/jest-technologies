# Jest Technologies

Light, editorial website for a software company. React + TypeScript + Vite + Tailwind, Framer Motion (fade-ins only), React Router.

    npm install
    npm run dev        # http://localhost:5173
    npm test
    npm run typecheck
    npm run build

Routes: / /about /services /projects /blog /blog/:slug /careers /contact (+ 404).
Colours and fonts live in tailwind.config.js. Company details and content live in src/data/*.ts.
Statistics, clients, projects, people, address, phone, and email are placeholders.
